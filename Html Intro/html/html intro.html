1.What Is Html

HTML stands for HyperText Markup Language.

HTML is used to create the structure of a webpage. It tells the browser how to organize headings, paragraphs, images, links, tables, and forms.

History of HTML

  • - 1991 Tim Berners-Lee introduced the first version of HTML.
  • - 1995 HTML 2.0 was published.
  • - 1997 HTML 4.0 was introduced.
  • - 2014 HTML5 became a W3C Recommendation.
  • - Today HTML is maintained as a Living Standard by WHATWG.

Why is HTML used?

  1. To create webpages.
  2. To display text, images, and links.
  3. To create tables and forms.
  4. To structure websites.
  5. To work with CSS for styling and JavaScript for interactivity.
